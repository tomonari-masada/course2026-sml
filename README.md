# 立教大学大学院 人工知能科学研究科 機械学習演習 プランナークラス

## 課題の提出方法
* 毎回の課題で、必ず提出しないといけないものは、次の二点。
  1. 授業で指定したPythonコード
  2. そのPythonコードを書いている途中で生じた、以下の三種類のいずれかの出来事の報告を、最低2件。
- [x] 「私が書いたコードを私自身はこう修正した」（よりよいコードを書けるようになったという、自分自身の気づきの報告）
- [x] 「私が書いたコードを生成AIはこう修正した」（AIによる文法エラーの修正、効率の悪いコードの効率化、等の報告）
- [x] 「生成AIが書いたコードを私はこう修正した」（課題の意図に合わないコードをAIが生成したので自分で修正した、等の報告）
- [ ] 「生成AIが書いたコードを生成AIはこう修正した」という種類の報告は、**提出してはいけません**。
