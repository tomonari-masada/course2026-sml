# 立教大学大学院 人工知能科学研究科 機械学習演習 プランナークラス

## 課題の提出方法
* 毎回の課題で、必ず提出しないといけないものは、次の二点。
  1. 授業で指定したPythonコード
  2. そのPythonコードを書いている途中で、「私が書いたコードを生成AIはこう修正した（文法エラー、効率の悪いコードの効率化、等）」、または、「生成AIが書いたコードを私はこう修正した（例えば、自分の意図に合わないコードをAIが生成したので修正した、等）」という報告を、最低2件。
* 「生成AIが書いたコードを生成AIはこう修正した」という報告は、提出してはダメです。そういう報告は要りません。
